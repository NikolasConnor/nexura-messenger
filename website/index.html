FAQ

Частые вопросы

Коротко о текущем статусе проекта.

Можно ли уже скачать Nexura?

Публичная загрузка APK пока не подключена. Мы добавим ссылку сюда после проверки файла и публикации стабильной сборки.

На каких устройствах будет работать приложение?

Nexura разрабатывается для Android. Совместимость зависит от версии Android и конкретной сборки; окончательный список требований будет опубликован вместе с релизом.

Все ли переписки зашифрованы?

Сквозное шифрование заявлено только для поддерживаемых типов переписок. Не следует считать, что все данные и все функции уже защищены одинаковым способом.

Куда сообщить об ошибке?

Откройте страницу проекта на GitHub и создайте обращение с описанием проблемы. Не публикуйте там пароли, токены, личные сообщения или другие секретные данные.

# Nexura Web

Первый веб-клиент Nexura. Публикуется по адресу:

`https://nikolasconnor.github.io/nexura-messenger/app/`

## Реализовано
- Вход и регистрация через существующий Supabase Auth.
- Восстановление браузерной сессии.
- Список личных и групповых переписок из существующих таблиц.
- История сообщений и обновление через Supabase Realtime.
- Адаптивный интерфейс для компьютера и телефона.
- Общий Rust/vodozemac Olm-криптомодуль, собираемый в WebAssembly.
- Браузерное хранилище криптосостояния: IndexedDB + неэкспортируемый AES-GCM ключ WebCrypto.
- Черновой адаптер с проверкой подписи OTK, проверкой параметров конверта и атомарной записью ratchet-состояния вместе с зашифрованной outbox-записью.

## Сборка локально

Требуются Rust stable, цель wasm32 и wasm-pack:

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-pack
wasm-pack build crypto-wasm --target web --out-dir ../web/src/crypto/pkg
cd web
npm install
npm run build
```

## Критические ограничения безопасности

- Веб-клиент пока **не отправляет сообщения**. Загрузка WebAssembly не означает, что E2EE включено.
- Для запуска защищённой переписки ещё нужно подключить серверную публикацию устройства и атомарное получение OTK, реальный интерфейс сравнения отпечатков, доставку зашифрованного outbox, восстановление после перезапуска и тесты Android↔браузер.
- Группы, медиа и несколько устройств в браузере ещё не готовы.
- Зашифрованные сообщения не показываются как обычный текст, если веб-клиент не может их проверить и расшифровать.
- Не добавлять plaintext fallback и не включать отправку до прохождения тестов совместимости и независимой проверки безопасности.

Используется только Supabase publishable key. Service-role/secret keys в браузер не добавлять.

# Nexura Web

Первый веб-клиент Nexura. Сборка публикуется как часть GitHub Pages сайта по адресу:

`https://nikolasconnor.github.io/nexura-messenger/app/`

## Что уже реализовано
- Вход и регистрация через существующий Supabase Auth.
- Восстановление сохранённой браузерной сессии.
- Загрузка списка личных и групповых переписок из существующих таблиц.
- Загрузка истории сообщений и обновление через Supabase Realtime.
- Адаптивная раскладка для телефона и компьютера.

## Важное ограничение безопасности
Android-клиент использует собственную реализацию E2EE (olm-v1), ключи устройств и конверты сообщений. В этом первом веб-клиенте криптографическая реализация ещё не подключена. Поэтому зашифрованные сообщения показываются как зашифрованные, а отправка сообщений намеренно отключена. Не включать отправку открытого текста и не добавлять обход E2EE ради видимости работающего чата.

Следующий этап — портировать и проверить совместимый веб-криптографический слой, включая управление устройствами, обмен ключами, восстановление защищённой сессии и медиа. До этого нельзя заявлять, что веб-клиент поддерживает E2EE.

## Локальный запуск
```sh
npm install
npm run build
```

Используется только Supabase publishable key. Service-role/secret keys в браузер не добавлять.

# Nexura Web

Веб-клиент Nexura. Публикуется по адресу:

`https://nikolasconnor.github.io/nexura-messenger/app/`

## Реализовано в веб-клиенте

- Вход и регистрация через существующий Supabase Auth и общие аккаунты Nexura.
- Список личных и групповых переписок, загрузка истории с постраничной подгрузкой и обновления через Supabase Realtime.
- Отправка текстовых сообщений в облачном и E2EE-режимах.
- Отправка до 10 вложений за один пакет выбора; каждый файл шифруется перед загрузкой в закрытое Supabase Storage.
- Просмотр фото, видео, аудио и файлов после скачивания и расшифровки.
- Общий Rust/vodozemac Olm-криптомодуль в WebAssembly.
- Браузерное хранилище криптосостояния: IndexedDB + неэкспортируемый AES-GCM ключ WebCrypto.
- Профили, фотографии, общая лента публикаций, истории на 24 часа и архив собственных историй.
- Группы, роли участников, реакции, закрепления, поиск, отложенные сообщения и уведомления.
- Аудио- и видеозвонки один на один через LiveKit (при настроенной инфраструктуре и разрешениях микрофона/камеры).
- Мультиязычная расшифровка голосовых сообщений через Whisper Tiny локально в браузере; аудио не отправляется на сервер распознавания.

## Сборка локально

Требуются Rust stable, цель wasm32 и wasm-pack:

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-pack
wasm-pack build crypto-wasm --target web --out-dir ../web/src/crypto/pkg
cd web
npm install
npm run build
```

## Ограничения и безопасность

- Не добавлять plaintext fallback и не отправлять незашифрованное содержимое в секретном режиме.
- Совместимость E2EE между Android и браузером, восстановление после потери устройства, доставка уведомлений и звонки требуют отдельного тестирования на реальных устройствах и с несколькими аккаунтами.
- Для медиа используется отдельное шифрование AES-GCM на клиенте; ключ и параметры расшифровки передаются внутри защищённого содержимого сообщения.
- В браузер добавляется только Supabase publishable key. Service-role/secret keys запрещены.
- Веб-клиент использует существующий проект Supabase и общую систему аккаунтов; отдельная база данных не нужна.

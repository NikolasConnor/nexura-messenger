FAQ / ПОДРОБНЕЕ

Хорошие вопросы — честные ответы.

Рассказываем о текущем состоянии проекта без обещаний того, чего ещё нет.

Можно ли уже скачать Nexura?

Да. Публичный Android-релиз 0.8.0 опубликован. APK можно бесплатно скачать по официальной ссылке на GitHub Releases.

На каких устройствах работает приложение?

Nexura разрабатывается для Android. Совместимость зависит от версии Android и характеристик устройства.

Все ли переписки защищены сквозным шифрованием?

Нет. E2EE реализовано не для всех типов переписок и функций. Не отправляй чувствительные сведения, исходя из предположения, что абсолютно все данные уже зашифрованы сквозным образом.

Веб-версия полностью готова?

Нет. Веб-версия доступна в предварительном режиме и имеет ограничения. Основной публичный релиз — Android-приложение.

Где сообщить об ошибке или предложить идею?

Создай обращение в GitHub проекта. Не публикуй пароли, токены, приватные ключи и личную переписку.

# Nexura Web

Первый веб-клиент Nexura. Публикация через GitHub Pages:

`https://nikolasconnor.github.io/nexura-messenger/app/`

## Уже реализовано

- Вход, регистрация и восстановление браузерной сессии через Supabase Auth.
- Список личных и групповых переписок, поиск пользователей по имени и username.
- История сообщений, Supabase Realtime и облачная история с клиентской расшифровкой.
- Защищённая отправка личных сообщений через общий Rust/vodozemac Olm-модуль в WebAssembly.
- Ответы, реакции, редактирование, удаление и пересылка сообщений в поддерживаемых личных чатах.
- Зашифрованные вложения и запись/отправка голосовых сообщений в поддерживаемых личных чатах.
- Персонализация темы переписки.
- Профиль: имя, аватар, биография, возраст и username.
- Настройки приватности: видимость онлайн-статуса и отчёты о прочтении.
- Блокировка и разблокировка пользователей.
- Закрепление сообщений и переход к закреплённому сообщению.
- Адаптивный интерфейс для компьютера и телефона.

## Ограничения и безопасность

- Групповая отправка сообщений в вебе пока отключена до завершения совместимости группового E2EE с Android.
- Голосовые и видеозвонки, истории, расширенное управление устройствами и часть фоновых функций Android пока не перенесены.
- Нельзя добавлять plaintext fallback или обходить E2EE ради совместимости.
- Функция считается перенесённой только после проверки на двух аккаунтах, повторного входа и синхронизации с Android.
- В браузере используется только Supabase publishable key. Service-role/secret keys запрещены.

## Сборка локально

Требуются Rust stable, цель wasm32 и wasm-pack:

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-pack
wasm-pack build crypto-wasm --target web --out-dir ../web/src/crypto/pkg
cd web
npm install
npm run build
```

GitHub Actions workflow `.github/workflows/web-ci.yml` собирает WebAssembly и проверяет production-сборку веб-клиента для изменений в `web/**`.
